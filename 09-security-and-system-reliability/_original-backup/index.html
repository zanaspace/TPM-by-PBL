Module 9.1

Authentication (AuthN) vs. Authorization (AuthZ)

Confusing these two concepts leads to catastrophic data breaches. Here is the exact distinction every Technical PM must draw:

Authentication (AuthN) — "Who are you?"

Verifying identity credentials before granting entry.

  • Passwords with bcrypt/Argon2 hashing and salting.
  • Multi-Factor Authentication (MFA / TOTP Authenticator apps).
  • OAuth 2.0 Social Login ("Sign in with Google / Apple").
  • Returns an identity token (JWT) verifying the user's ID.

Authorization (AuthZ) — "What can you do?"

Enforcing permissions and access boundaries once authenticated.

  • Role-Based Access Control (RBAC): Admin, Editor, Viewer roles.
  • Object-Level Access: Can User #402 view the medical records belonging to User #905?
  • Enforced by backend middleware on every single API request.
Module 9.2

The OWASP Top 10 Vulnerabilities Every TPM Must Guard Against

Vulnerability How It Happens Real-World Example TPM Mitigation Spec
BOLA / IDOR (#1 API Threat) API takes an object ID directly from the URL without checking if the requester owns it. Attacker changes GET /api/invoices/100 to /api/invoices/101 and reads someone else's invoice! Require middleware to verify invoice.user_id === current_user.id; use non-sequential UUIDs.
SQL Injection (SQLi) User input is concatenated directly into a database SQL query string. User enters ' OR 1=1; -- into login email field, bypassing authentication. Mandate parameterized queries and Object-Relational Mappers (ORMs).
Lack of Rate Limiting API allows infinite requests with no throttling, enabling brute-force password attacks. Bot tests 100,000 passwords in 2 minutes against /api/login. Specify Redis sliding-window rate limit (e.g. max 5 login attempts per 15 minutes per IP).
Module 9.3

Reliability Engineering: SLAs, SLOs, SLIs & Error Budgets

📊

SLI (Indicator)

The metric actually measured in real time. (e.g. "Percentage of API requests returning HTTP 200 in < 200ms over the last 30 days").

🎯

SLO (Objective)

The internal engineering target agreed upon between TPM and EM. (e.g. "99.9% of requests succeed").

📜

SLA (Agreement)

The external legal contract with customers with financial penalties if breached (e.g. refunding 25% of AWS bill if uptime drops below 99.5%).

Module 9.4: Real-World Public Product Case Studies

Case Studies: Apple & Cloudflare

Apple Inc.

Hardware-Isolated Security: The Secure Enclave

How Apple protects FaceID, Apple Pay, and biometric master keys from even root-level iOS exploits.

Secure Enclave Processor (SEP)

Separate Hardware Chip

Biometric FaceID mathematical models are stored on a physically isolated coprocessor with its own encrypted memory. The main iOS operating system never touches raw biometric data.

iCloud Private Relay

Dual-Hop Privacy Architecture

Uses dual-hop encryption: Apple knows your IP but not what site you visit; Cloudflare knows what site you visit but not your IP. No single entity has complete information.

Cloudflare, Inc.

Absorbing 71 Million Requests/Sec DDoS Attacks

Cloudflare uses Anycast routing and automated BGP routing to diffuse global volumetric cyberattacks across 300+ data centers.

Anycast Network

Distributed Blast Diffusion

Instead of 10 million bot requests hitting your origin server in New York, Anycast distributes the attack traffic to local edge nodes in Paris, Sydney, and Singapore where it is scrubbed.
